Explainable, Human-in-the-Loop Online Exam Proctoring

Laptop (primary) + mobile (secondary) cameras · temporal reasoning · cross-camera correlation · explainable risk — not a black-box cheating alarm.

Start the demo (two browser tabs on this laptop)

Use the same Session ID for both tabs so they connect to the same exam.

Tip: open the Candidate tab, enroll your face, start the exam — then open the Proctor tab to watch the analysis live. Try holding up a phone or looking away to see incidents build up.

1 · Detect

In-browser AI: face verification, multi-face detection, head-pose / gaze, and object detection (phone, book, extra person).

2 · Reason over time

A single frame is never "cheating". Signals are correlated across a sliding window into contextual incidents with confidence.

3 · Cross-camera

When laptop + mobile independently agree, an incident is cross-camera confirmed and trusted more.

4 · Explain & review

The proctor sees feeds, contributing signals, evidence and a timeline — and makes the final decision.
